# 💵 Cotação do Dólar - JavaScript
Link: 
Atividade desenvolvida para a disciplina de **Programação para Internet**.

A aplicação consome a API pública da **AwesomeAPI** para consultar a cotação do dólar (USD/BRL) e exibir as informações na página.

## 📌 Funcionalidades

* Exibe o valor atual do dólar;
* Exibe o maior valor do dólar no dia;
* Exibe o menor valor do dólar no dia;
* Atualiza os dados automaticamente a cada 10 segundos;
* Utiliza `fetch()` para consumir a API.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* API AwesomeAPI

## 🌐 API utilizada

[Acesse a documentação da AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas)
